# 篮球裁判系统

这是一个基于 uni-app + Vue3 开发的篮球裁判系统微信小程序版本，功能在网页版基础上有所完善，界面设计大致相同。
已获得软件著作权，并开源供RCer使用。

### 🏀 核心功能
- **计时系统**: 支持准备时间、比赛时间、控球变更时间等多种计时模式
- **得分系统**: 支持扣篮(7分)、三分球(3分)、二分球(2分)、运球(1分)等多种得分方式
- **犯规管理**: 完整的犯规记录和禁赛倒计时系统
- **控球变更**: 自动控球变更倒计时和手动控球变更功能
- **历史记录**: 详细的得分和犯规历史记录

## 项目结构

